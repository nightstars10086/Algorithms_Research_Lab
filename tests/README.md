# tests

这里存放算法和模型核心实现的自动化测试，包括确定型算法的正确性、边界情况，以及深度学习模块的数值与梯度检查。

路径建议：

```text
tests/<topic>/test_<algorithm_name>.py
```

运行全部测试：

```bash
python -m pytest
```

对于 K-means、PCA、遗传算法这类概念实验型算法，测试可判定的核心计算与明确假设下的稳定性质，整体行为放到 `projects/` 验证。不要在没有理论保证的情况下断言所有算法的损失每步都下降。

深度学习测试随实现放到 `tests/deep_learning/`，可用小输入的预期值、框架输出对照、梯度对照或有限差分验证。API 对照要统一权重、模式和误差容限；随机训练的准确率不作为脆弱的精确断言。当前只有目录结构检查，不代表算法正确性或训练已经验证。
