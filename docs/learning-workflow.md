# 算法学习流程

这份文档定义仓库里的标准学习流程。以后每新增一个算法，都可以照着这个流程走，确保学习过程从“看懂”推进到“能实现、能验证、能复述”。

## 1. 建立任务卡

在 `docs/algorithm-index.md` 新增一行：

- 算法名称
- 所属分类
- 学习类型
- 学习状态
- 源码路径
- 笔记路径
- 验证路径

状态建议使用：

- `todo`：准备学习
- `reading`：正在理解原理
- `coding`：正在实现
- `testing`：正在补测试
- `reviewed`：已完成复盘

## 2. 判断学习类型

先判断它属于哪一类：

- 确定型算法：有清晰输入、输出和可判定答案，例如排序、二分、最短路、背包。
- 概念实验型算法：更像一种建模方法、优化过程或数据分析思想，例如 K-means、PCA、梯度下降、遗传算法。

两类算法都值得学，但记录方式不同。不要强行把 K-means 这类算法写成简单的“输入一个列表，输出一个答案”。

这一区分用于选择记录方式，不意味着模型核心不能测试。深度学习采用 [专项路线](deep-learning-roadmap.md) 的 **from-scratch → PyTorch API → experiment** 三层学习法：核心运算做数值与梯度检查，整体模型做小型实验。

## 3. 创建笔记

通用入口模板：

- `docs/templates/algorithm-note-template.md`

确定型算法模板：

- `docs/templates/deterministic-algorithm-note-template.md`

概念实验型算法模板：

- `docs/templates/concept-experiment-note-template.md`

复制合适模板到 `docs/notes/<topic>/<algorithm_name>.md`。

先写这些内容：

- 问题背景
- 应用场景
- 学习类型
- 核心概念
- 一个直观例子或小实验设想

这一阶段的目标是先知道算法为什么存在。

## 4. 推导原理

在写代码前，先把核心逻辑写成自然语言或伪代码：

- 朴素思路是什么？
- 朴素思路为什么不够？
- 这个算法用什么信息减少重复计算或无效尝试？
- 每一步维护什么状态或不变量？
- 如果是迭代型算法，每轮迭代在优化什么？
- 如果是概率或统计算法，它依赖什么假设？
- 什么时候结束？

如果这部分写不清楚，先不要急着编码。

## 5. 编写实现

源码放在 `algorithms/<topic>/<algorithm_name>.py`。

实现建议：

- 先写清晰版本，变量命名尽量表达含义。
- 函数加简短 docstring，说明输入、输出和复杂度。
- 对非法输入做必要处理。
- 暂时不要为了炫技压缩代码。
- 只保留最小核心，导入时不下载数据或启动训练；完整实验放在 `projects/`。
- 框架对照要说明输入、参数、形状和数学约定；使用自动求导时明确手写部分的边界。

## 6. 编写示例

示例放在 `examples/<topic>/<algorithm_name>_example.py`。

示例要回答一个问题：这个算法在实际场景中怎么被调用？

可以包含：

- 一组直观输入
- 打印结果
- 简短场景说明

## 7. 选择验证方式

### 确定型算法

测试放在 `tests/<topic>/test_<algorithm_name>.py`。

至少覆盖：

- 正常案例
- 空输入或最小输入
- 重复元素、负数、极端值等边界情况
- 能暴露常见错误的案例

### 概念实验型算法

小型项目放在 `projects/<topic>/<algorithm_name>/`。

建议包含：

- `README.md`：说明项目验证什么问题。
- `run.py`：可重复运行的小实验。
- 按需要添加数据生成脚本或小数据集，不预建空 `data/`。
- 图表、指标或实验输出按需要保存，不提交大型数据集和权重。
- `report.md`：记录观察、解释和失败案例。

记录依赖版本、设备、随机种子、超参数、数据划分和运行方式。项目复用核心实现，探索 notebook 最终要能重启后从头运行。学习过程中不必一次创建所有示例、笔记和实验文件，先围绕当前问题完成最小闭环。

验证可以使用：

- 指标变化，例如聚类内平方和、准确率、损失下降。
- 可视化结果，例如 K-means 聚类散点图。
- 稳定性观察，例如不同随机种子是否得到相近结果。
- 消融实验，例如改变 K 值、初始化方式或迭代轮数。

## 8. 运行验证

运行：

```bash
python -m pytest
```

概念实验型算法运行项目脚本：

```bash
python projects/<topic>/<algorithm_name>/run.py
```

## 9. 复盘与归档

验证完成后，回到笔记补充：

- 复杂度分析
- 正确性、收敛性或有效性解释
- 易错点
- 与相似算法的区别
- 是否能脱离资料复述

最后把 `docs/algorithm-index.md` 中状态改为 `reviewed`。
